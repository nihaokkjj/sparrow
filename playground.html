Sparrow · AI Playground

Prompt → Provider → Chunk Buffer → JSON Spec → SVG

A minimal lab for turning natural language into a Sparrow plot spec, streaming model chunks, parsing JSON progressively, and rendering the result with renderPlotSpec().

Minimal by design The mock provider works out of the box. Switch to an OpenAI-compatible endpoint when you want real model output.

Input

The mock mode returns chunked Markdown with a fenced JSON block, so you can watch the parser recover the spec before rendering.
