AI Sparrow

这是一个轻量级演示页面，可将自然语言转换为 Sparrow 图表规范，实时接收 模型分块输出，渐进解析 JSON，并通过 renderAISpec() 渲染最终结果。

极简设计 默认的 mock provider 开箱即用；如果你想查看真实模型输出，可切换到兼容 OpenAI 的接口端点。

Input

Keep this on to let renderAISpec() rebalance crowded flat row/col specs into a near-square grid based on canvas size. Turn it off to preserve the model's original layout exactly.

现在可自由选择浏览器直连，或走同源代理再转发到官方接口 / 中转站地址， 不再需要把目标地址直接写死在本地配置里。
